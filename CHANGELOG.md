- Integrated the exact-build Bedrock adapter into the main application, with native Reach, virtual targeting Hitbox, input-camera Aim, incoming-motion Velocity, local Timer, Zoom, Auto 360, Clicker actions and contextual mining.
- Connected all typed module settings; added physical-stream Triggerbot/priming/inversion, real polling Tuner, Auto/Legit mining and observed-attack S-Tap with owned-key cleanup.
- Added explicit F8 arming, F9 stop, native UWP capture detection, session/world/heartbeat guards, native target revalidation and callback draining. Timer and FOV restore their owned baselines.
- Separated requested output, native actions, actual component observations and independent server events in diagnostics. Missing motion observations are reported as unavailable.
- Reduced measured disabled-adapter callback overhead from approximately 17.50 ms to 3.17 ms on the development fixture. Preserved average CPS under low polling rates without catch-up bursts.
- Added the optional original private-world observer, reproducible scenario plans, runtime contract, requirements map, measured validation and portable client/bridge packaging.
- Final automated regression: 34 core/platform cases and 13 service integration tests passed. Main-client combined combat, Auto Walk, F9, focus loss and inventory interruption were verified in a disposable world. See `docs/VALIDATION.md` for measured results and manual coverage limits.

This adapter supports only Store x64 build 1.26.6005.0 with the documented executable hash. The development binaries remain unsigned; no production service or certificate is configured.
