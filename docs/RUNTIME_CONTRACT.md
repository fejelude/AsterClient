# Bedrock runtime contract

Implementation work started 31 October 2026 against the supplied 23-page ASTER Bedrock Lab guide. Its screenshots and recommendations are requirements evidence, not test results. Independently chosen meanings below resolve the ambiguities identified by that guide and the original specification.

The native adapter is restricted to Store x64 build `1.26.6005.0`, SHA-256 `988f6a61403b4381aa41e6c66d64cce441b14e561a9b10f647c2758ef3f2672a`. Other binaries must pass independent research and testing. There are no security-setting changes, kernel components, or anti-cheat bypasses.

## Shared conditions and ownership

- Saved enable state never arms a session. F8 explicitly arms in a focused world. F9, Stop, client exit, lost heartbeat, missing player, and incompatible layout stop effects. A fresh arm is required after focus loss or opening a game screen.
- Gameplay requires an exact binary match, a verified local actor, foreground Minecraft, and a native mouse-capture transition (`gameplay_captured`). Capture is observed without constructing game-owned strings. Frame effects run from the native client update; incoming motion is handled at its native receive callback. IPC has a version, session identity, pinned world generation, monotonic heartbeat, and separate requested/applied/observed telemetry.
- Combat Mode means the physical attack button is held (after Invert mapping where applicable). Only Moving means horizontal velocity greater than 0.01 blocks per tick or a physical movement key. It is the same condition across modules.
- CPS, steering, spins, and S-Tap duration use monotonic real time, independently of Timer. Timer affects the local simulation clock, never a claimed remote-server clock.

## Settings and effects

| Module | Explicit contract |
|---|---|
| Reach | Maximum eye-to-ray/AABB intersection distance in blocks, 3–10. This is entity targeting, not block reach. Native attack dispatch and target hurt-state observations are separate counters. Server acceptance is measured in a private world and cannot be promised on other servers. |
| Hitbox | Absolute full horizontal targeting width in blocks; target height is retained. Uses a virtual ray-query box, leaving physical world collision geometry intact. Combined with Reach it changes the box once and tests a single ray distance. Deterministic selects the nearest intersection with entity ID as tie-breaker; OFF prefers the still-eligible previous target. |
| Aim Assist | Target anchor is collision-box center plus Height in blocks. First FOV is the outer angular cone in radians; second is the inner dead zone in radians. Horizontal-only computes yaw eligibility and never writes pitch. Higher Smoothness slows the response. Closet is a bounded proportional correction; Blatant has a higher angular-rate limit. Avoid Walls uses voxel occlusion (including glass); Avoid On Target suspends correction while the unexpanded box intersects the view ray. Cache Targets retains a valid target only within the same registry/world. Antibot restricts to structurally valid player entities; it does not claim to detect every server NPC. |
| Velocity | Percentage ON displays percentages; OFF displays normalized 0–1 factors. Stored values remain percent. Precision controls hundredth-percent versus whole-percent input steps. Bind the local actor's incoming SetActorMotion callback, validating packet identity, runtime ID and finite vector. Combine Modifiers ON scales total incoming velocity; OFF scales its delta from local velocity immediately before receipt. X/Z and Y are independent. No Backwards removes the modified horizontal impulse opposite the facing direction. Combat Mode uses the shared condition. The borrowed packet vector is restored after native handling. Requested vectors, actual component values after receipt, client displacement and server observations remain separate measurements. |
| Timer | Local simulation TPS field is `20 × multiplier`, with ownership checked on every write. Restore the previous baseline on disable/stop. Count actual local actor ticks per monotonic second; arithmetic requested TPS and measured TPS remain separate. |
| Clicker | Independent physical hold streams and real-time CPS clocks. Invert swaps logical left/right output. Left Priming: hold left and tap right; Right Priming is mirrored. Priming resets on release/stop. Randomize independently scales each interval uniformly by 0.88–1.12. No catch-up bursts. Triggerbot allows the left stream without a held left button only while an unobstructed eligible entity intersects the targeting ray. |
| Tuner | Scheduler polling frequency in Hz, 0 = automatic (1000 Hz while armed); nonzero clamped to 50–1000 Hz. It changes wake precision, not CPS or the game clock. A high-resolution waitable timer and temporary process-owned Windows timer-resolution request are active while armed and released afterward. Disarmed polling is 60 Hz. |
| Break Blocks | Auto immediately preserves a held mining action when a block is targeted. Legit waits for 250 ms of continuous logical attack hold on the same block before preserving it. Invert maps the physical right button to this attack hold. Repeated clicks resume when the block is no longer targeted. Auto takes precedence if both options are enabled. Normal Bedrock breaking time and authority remain in force. |
| Auto 360 | A complete 360-degree yaw turn during a valid combat/attack sequence. Speed is turns per second; Step is a minimum angular update in turns. Left/Right are relative direction weights; both zero pauses. Interval is real-time milliseconds between turns. Spin owns yaw while a turn is in progress, and Aim resumes afterward. |
| Zoom | Camera zoom enabled by the module toggle/hotkey. The target is 0.35 times the original FOV in radians. Speed 0 is immediate; 1–100 uses a 644–50 ms transition. Restore the owned original camera field on disable/stop. Low CPU selects 100 Hz host polling when Clicker and movement automation are disabled. |
| Auto S-Tap | After an observed attack, while physically moving forward, briefly release forward/sprint and hold backward for 60 ms. Restore still-held physical Forward after completion or explicit F8/F9 cancellation in the focused captured world. Focus/menu/world interruption releases owned synthetic keys without typing a restore press into another screen. No retrigger until the current tap ends. |
| Sprint / Auto Walk | Existing foreground-only synthetic key ownership. Sprint pauses during S-Tap. Stop releases synthetic holds. |

## Evidence and release status

Runtime binding is not verification. Every module needs a baseline, enabled measurement, disabled measurement, and repeatable results. Raw development evidence belongs under ignored `test-results/`; a reviewed summary belongs in `docs/VALIDATION.md`. Do not promote unavailable telemetry to zero or an enable checkbox to success.

The [validation report](VALIDATION.md) records the tested baselines, enabled effects, restoration and independent server events. Physical-input planner tests, OS delivery, native component observations and accepted server actions establish different things; unavailable observations are never reported as measured zero.
