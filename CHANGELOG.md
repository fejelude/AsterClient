# 0.1.0-dev - October 30, 2026

- Native Windows x64 control window with an original animated theme and the reference navigation/control groups.
- Typed, independently saved Aim profiles; validated numeric ranges; atomic configuration, migration, backup and corruption recovery.
- Verified Microsoft Store package/build/architecture detection and foreground/cursor gates; per-module runtime states.
- Physical-input observer that rejects injected events; independent mouse schedulers, priming, randomization, logical inversion, Sprint and Auto Walk.
- Own-service activation, Windows Credential Manager, signed entitlements, rotation, revocation and offline grace.
- Authenticated release-feed checks and fail-closed executable verification; no automatic replacement of the running app.
- Previewable local diagnostics, bounded structured logs, graphics recreation, tray restoration and safe worker shutdown.
- Automated core, native platform and client/server integration tests.

Not delivered as working game-engine features: Reach, Aim Assist, Hitbox, Velocity, Timer, Zoom, Auto 360, Auto S-Tap, Triggerbot, Tuner or block-breaking modes. Input streams are verified in a Win32 fixture, not in a Minecraft world. No public signing certificate or hosted services are configured.
